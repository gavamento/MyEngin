MyEngine の使い方
==================

1. このフォルダを好きな場所に置く
   (zip を展開した場所のままでもかまいません。OneDrive の同期フォルダは避けてください)

2. Setup.bat をダブルクリックする
   - 足りない物を自動で入れて、最後にエディタを起動します。
       Visual C++ 再頒布可能パッケージ / .NET 8 ランタイム / Git for Windows
   - 途中で「C++ スクリプトも使いますか？」と聞かれます。
     y と答えると Visual Studio 2022 Build Tools (数 GB) も入れます。C# スクリプトだけなら不要です。
   - 管理者の確認が出たら「はい」を選んでください。
   - 何度実行してもかまいません (入っている物は飛ばします)。

3. 2 回目からは Editor.bat でエディタを起動できます

「Windows によって PC が保護されました」と出たら
  「詳細情報」→「実行」を押してください (署名の無いプログラムに出る表示です)。

winget が無いと言われたら
  Microsoft Store で「アプリ インストーラー」を入れてから、もう一度 Setup.bat を実行してください。
