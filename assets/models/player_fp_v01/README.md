# プレイヤーの腕・足：確認用初版

2026-09-09。男性研究員の一人称用の左右の腕・脚。白衣風の袖、手袋、暗色のズボンと靴。頭・胴体は含まない。年齢を判別する顔の造形はない。

- `Player_Researcher_FP.fbx`: 22メッシュ、13,824三角形、35ボーン、最大2ウェイト。
- `Player_Researcher_Review.blend`: Blender 5.1.1編集原本、リグ、撮影環境。
- `textures/`: 4材質のBaseColor・Normal・Normal_DX、各2048角、12枚。FBXと一緒に保持する。
- `previews/`: overview・hands・first_personの通常照明画像。
- `validation_blender.json`: 実FBX再読み込み検証の結果。

単位はメートル。原本はZ-up、前方-Y。FBXはY-up、-Z forward設定で出力。ゲーム向けNormal_DXとBlender向けNormalを分け、既存研究所ツールのPhysicalMaterial出力補助を使用。

## アニメーション

待機3秒、歩行1.2秒、走行0.8秒、しゃがみ歩行1.8秒。全て60fps、その場ループ。FBX再読み込み時はフレーム1から始まり、クリップ名にResearcher_Rig接頭辞が付く。原本では確認用NLAトラックはミュートしてあり、Action Editorで目的のアクションを選んで確認する。

## 検証済み

BlenderでFBXを読み直し、22メッシュ・35ボーン・4クリップ、三角形、UV1セット、画像の存在と解像度、最大4影響以下とウェイト正規化を確認。全544フレームのスキニング座標が有限で、各ループの端点差は0。検証終了コード0。画像3枚のうち全体と手元は目視確認済み。

## 未完成箇所・使用上の制限

これは造形確認用の初版であり、写実的な完成品質ではない。袖口と手袋の交差、単純な指の接続、布のしわ・縫い目・汚れのディテールに改善が必要。手指は別メッシュが重なる構造。指関節はあるが独立した指の演技は未作成。

動作はプロシージャルな仮アニメーション。歩行・走行の足底が約5mm床下へ入り、しゃがみ歩行の最下点は約10cm浮く。しゃがみの胴体の下降と接地、足滑りの補正が必要。全フレームの自己交差、動作遷移、ufbx互換性検証、エンジン内表示・カメラとの重なり・操作連動・実機60fps測定は未実施。60fpsベイクは実機60fpsの保証ではない。投擲、光の設置・回収動作は含まない。

生成元は `tools/player_fp_v01/build_player.py`。既存出力がある場合は停止する。検証は `tools/player_fp_v01/verify_player.py` をBlenderのbackground / factory-startup / python-exit-code 1で実行する。再生成時は既存の手編集を保護し、新版出力先を使用する。
