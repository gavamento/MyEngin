# 地下廃研究所：部屋・通路セット v01

今回の確認対象は、試験室とL字通路、および配置用の備品です。
プレイヤー、敵、懐中電灯は含みません。既存エンジンのコードやシーンは変更していません。

## ファイル

| ファイル | 内容 |
|---|---|
| `Lab_Room.fbx` | 内寸10m x 8m、天井高3mの試験室。壁・床・天井・配管・換気口・消灯した照明器具 |
| `Lab_Corridor.fbx` | 幅2.5m、中心線長15mのL字通路。曲がり角の先は閉じた終端 |
| `Lab_Bench.fbx` | 実験台。引き出しは静的な形状 |
| `Lab_Sink.fbx` | 流し台・蛇口・下部収納。扉と蛇口は静的な形状 |
| `Lab_StorageShelf.fbx` | 金属製の収納棚 |
| `Lab_MetalFloorPlate.fbx` | 床に重ねる滑り止め付き金属板 |
| `Lab_GlassShards.fbx` | ガラス片のまとまり |
| `Lab_WaterPuddle.fbx` | 床に重ねる水たまりの表面 |

| `Lab_Review.blend` | 全体配置、編集可能なメッシュ・UV・材質・扉リグ、確認用カメラと照明 |

| `previews/` | 通常照明による外観確認画像。ゲームの暗闇・音波の再現ではない |

## MyEngine向け仕様

- FBXはBlender 4.2のバイナリー出力。単位はメートル。
- MyEngineのufbxローダーが左手系・Y-upへ変換する前提。
- 配置は `asset_manifest.json` の `engine_position` を使用。回転ゼロ、スケール1。
- 部屋の原点は床中央。通路の原点は入口中央、部屋側から見て奥に進んで右折する構成。
- 各備品はローカル原点に書き出し、床置き用の高さを維持。
- 全メッシュを三角形化。UVは1セット。繰り返し使用する材質のUVは0～1の外側も使用。
- 錆と金属を別マテリアルとして使用。金属度と粗さはマテリアルごとの数値。
- 色テクスチャはsRGB、ノーマルはリニア。
- FBXは `_Normal_DX.png` を参照。MyEngineのV反転と導関数による接空間に合わせて緑成分を反転。
- Blenderの確認用ファイルは `_Normal.png` を使用。両者を入れ替えないこと。
- 水たまりとガラスは現行エンジンで扱える半透明材質。屈折や水面シミュレーションは含まない。
- `textures` フォルダーをFBXと一緒に保持。相対参照で、画像はFBXへ埋め込んでいない。
- 照明・カメラはFBXに含めない。天井の照明器具も発光しない。

## 扉

- `DoorRoot` と `DoorHinge` の2ボーン。各頂点の影響ボーンは1本、ウェイト1。
- `Lab_Door_Rig|00_Door_Open` と `Lab_Door_Rig|01_Door_Close` の2クリップ。各1秒、0～60フレーム、60fps。
- 蝶番を支点に90度開閉。廊下側へ開く。
- FBX読み込み時に先頭クリップが自動再生されるエンジン仕様に注意。
  閉じた扉として置く場合は開くクリップの時刻0で停止し、操作時に再生する。
- FBX材質は読み込み側が認識するPhysical Materialのプロパティを付けて出力。
  標準の色・ノーマル参照も保持し、エンジンの読み込み設定は変更していない。
- 衝突判定、開閉操作との接続、足音用の床種別設定はゲーム側の作業。
  このセットはそれらを既存シーンへ自動登録しない。

## 制作・検証

生成元は `tools/lab_assets_v01/build_lab.py`。
`finish_lab.py` は生成済みセットの材質を整えて再出力する補助スクリプト。
`verify_fbx.c` はリポジトリ内のufbxを使い、読み込み・UV・画像参照・材質・ウェイト・開閉を検査する。

`Lab_Review.blend` の `PREVIEW_ONLY_NOT_EXPORTED` は確認用照明とカメラ。
レンダーに見える明るさは材質と形状を確認するためのもので、ゲームの照明設定ではない。

全素材はこのセット用に手続き生成したもの。外部の写真・購入モデルは使用していない。

## 検証結果

- FBX 9ファイル、合計153,156三角形。
- 13材質、39枚の2048 x 2048 PNG（色・Blender用ノーマル・エンジン用ノーマル）。
- リポジトリ内のufbxとエンジンと同じ座標変換設定で読み込み成功。
  UV・法線・画像参照・金属度・粗さ・透明度・ウェイト・扉の90度開閉を確認。
- BlenderへのFBX再読み込みでメッシュ数・三角形数・UVを確認。
- 5方向のレンダーを確認。画像が空白や真っ黒でないことも数値で検査。
- 詳細は `validation_ufbx.txt` と `validation_blender.json`。
- MyEngineの実行画面上での表示・当たり判定・ゲーム操作との接続は未検証。

編集後にエンジン向けFBXだけ再出力する場合は、Blenderのバックグラウンド実行で
`tools/lab_assets_v01/finish_lab.py` に `--export-only` を渡す。
通常のBlenderのFBX書き出しだけでは、今回のPBR互換プロパティは付与されない。
