## 1. テストの目的と手順

Thingi10K を含む全 12,986 サンプルで統合本学習を完走した Deep-Modal ネットワークからエクスポートした `.dmnet` について、実際に PCM 音響波形を合成（`ModalSynthRender` による 2 次再帰共振器合成）し、以下の品質基準を検証した：

1. **材質スケール則の正確性**:
   - 金属（Metal: $E=7.0\times 10^{10}, \rho=7850, \alpha=6, \beta=10^{-7}$）
   - 木材（Wood: $E=1.1\times 10^{10}, \rho=700, \alpha=10, \beta=2\times 10^{-6}$）
   - ゴム（Rubber: $E=1.0\times 10^8, \rho=1100, \alpha=20, \beta=10^{-5}$）
   - ガラス（Glass: $E=6.0\times 10^{10}, \rho=2500, \alpha=4, \beta=5\times 10^{-8}$）
2. **打撃位置（接触 cell）による音色差**:
   - 物体上部（Top）、側面（Side）、角部（Corner）での加振方向・接触面によるモード励起差。
3. **物体サイズ（$L$）と周波数反比例スケール則**:
   - 大型プロップ（1.35m `sink`）、標準（1.0m `box`）、小型プロップ（0.06m `avocado`）。
4. **ダイナミックレンジと音量較正**:
   - 基準衝撃力（$J = 6.0\ \mathrm{N\cdot s}$）においてクリッピング（歪み）せず適切な peak dBFS（約 -12 dBFS 近辺）に収まっているか。

## 3. 音響品質の総括評価

1. **材質感の再現性（優）**:
   - Rayleigh 減衰パラメータおよび剛性・密度の違いがそのまま「金属のキーン」「ガラスのチーン」「木のコン」「ゴムのボム」という聴感上の劇的な差となって現れている。
2. **位置依存性（優）**:
   - 同一の力積でも、打撃する場所（法線と接触セル）によって励起されるモード数や基本周波数が明確に異なり、均一なサンプル再生音とは異なるインタラクティブな打撃感が得られる。
3. **音量バランス（優）**:
   - `ampScale = 11478.0` の較正により、基準衝突（$J=6.0\ \mathrm{N\cdot s}$）でピーク値が -10 〜 -16 dBFS（目標設計値 -12 dBFS ± 3 dB）に完全に一致。
   - `SoftClip` による歪みも生じず、自然なダイナミクスが確保されている。
