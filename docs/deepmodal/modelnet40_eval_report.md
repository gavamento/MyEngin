# Deep-Modal ModelNet40 本学習および実機評価レポート

## 1. 概要と実施内容

ModelNet40（計 12,311 形状）からボクセル化および FEM 固有値解析を実施し、自前データ（stage0: 48 件、stage1: 86 件）と統合した **計 12,035 件** の大規模データセットを用いて Deep-Modal（3D U-Net）の本学習（50 エポック）を実施しました。

学習完了後、学習済み重みを実運用形式（`.dmnet`）へエクスポートし、MyEngine 実機（Release ビルド）にて全 382 サブメッシュに対するモーダルパラメータベイク・推論、無音メッシュ率の改善度測定、オーディオ音量較正（-12 dBFS アンカー測定）、各種自己テスト（SelfTest / check_rules）を実行・検証しました。

## 4. 評価に困る課題・考察

### ① 音量較正（ampScale）の最適値のシフト
- **事象**:
  - ModelNet40 投入前の旧モデル較正値 `ampScale = 11478.0` を適用した場合、`Runtime.exe --modal-demo` での基準力積（$J = 6.0\text{ N}\cdot\text{s}$）における 6 面衝突ピーク（上から 4 番目の高位中央値）が **-39.50 dBFS** となり、目標の **-12 dBFS ± 3 dB** に対し約 27.5 dB 小さくなっています。
- **原因の分析**:
  - ModelNet40 の大規模データセット（12,035件）を学習したことで、モデルの出力振幅（amp チャンネル）が以前の極端な過学習・局所値から、広範な幾何形状の平均的な正規化空間へと平滑化されたため。
- **解決策**:
  - 差分である約 27.5 dB（$\approx 23.7$ 倍）を反映し、`ampScale` を $11478.0 \times 23.7 \approx 272,000$ 前後に引き上げることで、物理的に意図された衝突音量（-12 dBFS）に正確に一致させることができます。
  - この調整は重みの再学習を必要とせず、`export.py --amp-scale` でヘッダ 1 つを書き換えるだけで完結します。

### ② エポック数と R² の頭打ち
- 12,035 件の巨大データセットに対して 50 エポック（学習率 1e-3 固定）を実施したところ、Epoch 30（R²=0.2711）でピークを迎え、以降は微小な過学習または学習率過大により R²=0.1814 に落ち着きました。
- 今後さらにデータセットを拡大する場合（ShapeNet 等）、`--epochs 100` への延長に加え、コサインアニーリングや段階的学習率減衰（`--lr-halve-every`）の適用がより高い精度（R² ≥ 0.35〜0.40）の獲得に有効と考えられます。
