# デモ動画 台本 (約 5 分 / 2 本立てにも切れる)

**構成の意図**: このエンジンのポートフォリオとしての主張は 2 つある —
「**エンジンで実際にゲームが作れる**」と「**エンジン単体の技術深度**」。前半 (第 1・2 部) が前者、
後半 (第 3 部) が後者。時間が取れないときは **第 1・2 部を「ゲーム編」、第 3 部を「エンジン編」**
として 2 本に割ってよい。

## 事前準備

- **実 GPU で撮る** (`--warp` は使わない)。録画は 1600x900 以上
- エンジンリポジトリ: `main.scene.json` を削除した状態 (既定デモが自動構築される)
- 外部プロジェクト: 仮ゲーム **HAL Collector** と **三校プロトタイプ**を開ける状態にしておく
  (どちらも `--project DIR` で開く。エンジンリポジトリの中には無い)
- VS で `MyEngine.sln` を開いておく (第 3 部のホットリロード用)
- ★ **三校プロトタイプで Ctrl+S を押さない** — `--acoustic-demo` は `scenePath_` が
  `assets\scenes\main.scene.json` に落ちるので、保存すると以後の既定デモが壊れる

# 第 1 部 — エンジンで作ったゲーム (約 1:40)

## 0:00 プロジェクトを開く (15 秒)

1. `Editor.exe` を裸で起動 → **プロジェクトマネージャ**が出る
2. 「HAL Collector」を選んで開く
3. 一言: 「**これはエンジンリポジトリの外のプロジェクト**。エンジン側の C++ には
   このゲームのコードもシーンも 1 行も無い。`--project` で開いて、スクリプトを書いて、
   アセットを置いて作った」

## 0:15 一周する (60 秒)

1. **タイトル** → `Enter` (Confirm) でゲームへ
2. `WASD` で歩く / **`V`** で一人称 ⇄ TPS 切替 / `Space` でジャンプ
3. アイテムに**歩いて触れると回収**される (トリガー層 = 当たり判定で拾う) → スコアが増える
4. `J` (Fire) で撃つ → 敵に当たるとエフェクト
5. `E` (Interact) で**車に乗り降り**し、走る (レイキャストサスペンション + タイヤ力)
6. `Escape` でポーズ → 解除
7. リザルト画面 → **ハイスコアが前回の記録として残っている** (`PersistStore` + `SaveGame`)
8. `F3` でデバッグ表示のオン/オフ

## 1:15 何を見せたか (25 秒)

Inspector を開いて示す:

- **入力はアクションマップ** (`assets/input/actions.json`)。`MoveX/MoveY/LookX/LookY` の軸と
  `Jump/Fire/Pause/SwitchView/Interact/Confirm/DebugToggle` のアクション。
  キーボードとパッドの両方が同じ 1 つの表から来ている
- **調整値はスキーマコンポーネント** (`GameTuning`)。日本語ラベル付きのスライダが
  自動生成され、Play 中に触ってその場で効く (engine_spec §5.2 の規約)
- 一言: 「**この経路で踏んだ穴は全部 [`docs/dogfooding.md`](dogfooding.md) に書いてある**。
  20 件のうち 3 件はエンジンを直して (M64a / M64b) 解決、17 件は未解決の台帳として残している」

# 第 2 部 — 三校プロトタイプ: 音が世界を描く (約 1:00)

`Editor.exe --acoustic-demo` (または三校プロジェクトを開く)。**Editor で起動する** —
第 3 部で SceneView の「音響」トグルを使うため (Runtime にはこの窓が無い)。

## 1:40 止まると何も見えない (35 秒)

1. **立ち止まる** → 画面はほぼ真っ暗。足元だけがうっすら見える (呼吸)
2. `WASD` で歩く → **音の波が広がり、当たった壁と床だけが光って形を描く**。
   L 字の廊下が、角を回り込む波で少しずつ見えてくる
3. `Shift` で走る → 波が大きく、遠くまで一気に届く。**見える範囲が広がる**
4. `Ctrl` でしゃがむ → 波が小さくなる
5. **床材で音が変わる**ことを見せる (カーペット → 金属板を踏み替える)
6. `Q` で石、`E` で瓶を投げる → **着弾点で波が生まれ、そこの地形だけが一瞬見える**

## 2:15 音は敵にも届く (25 秒)

1. 赤い敵 (**聴覚センサー**) が、こちらの立てた音の方へ寄ってくる
2. 緑の敵 (**光センサー**) は置いた光に寄る。**FSM は同じで、載っているセンサーだけが違う**
3. `F` 長押しで光を設置 → **2.5 秒かかり、その間は動けない = 音が出ない = 何も見えない**。
   「暗闇の中で無防備に立つ 2.5 秒」がこのゲームの核心
4. `V` で一人称に切り替えて同じ場所を見る

# 第 3 部 — エンジンの中身 (約 2:20)

## 2:40 1 枚の場が 4 つの役を持つ ★技術的な山場 (35 秒)

三校プロトタイプのまま、SceneView の **「音響」トグル**を入れる。

1. ボクセルの波面が可視化される。整数チャンファ距離 (26 近傍の `<11,16,19>`) を
   **1 tick に 1 リング**ずつ広げている
2. 一言: 「**この 1 枚の場が 4 つの役を同時に持つ**」
   - 残光ボリュームとして**世界を描く**
   - 敵 AI の**聴覚**になる (到来方向つき)
   - 同じ重みから引いた**ナビゲーション**になる
   - M68 で**プレイヤーの耳**になった。角を回る音は戸口へ音源ごと移して回折ローパスを掛け、
     パンナーは壁を知らないまま正しい方向へ鳴る
3. 「**sim 状態は波スロット表だけ**。場も残光もリスナー場も派生値なのでハッシュに載らない。
   だから M68 を通してリプレイ 7 ペアと golden 22 枚が 1 ビットも動いていない」

## 3:15 C++ ホットリロード ★目玉 (40 秒)

エンジンリポジトリの既定デモに戻る。

1. Play したまま VS で `Rotator.cpp` の回転軸を Y → X に変更 → GameLogic のみリビルド
2. 1〜2 秒で挙動が変わる。**角度 (状態) は継続し、`Start` は再実行されない**
3. フィールドを 1 個追加してリビルド → Console に「layout migrated」、
   Inspector に新フィールドが既定値で出現 (既存値は保持)
4. 新しいコードにブレークポイントを置いて止まることも見せる (PDB コピー + `/PDBALTPATH`)
5. 一言: 「**スクリプトの状態はエンジン側の ECS に置いてある** (ADR-003)。
   だから DLL を差し替えても退避・復元が要らない」

## 3:55 シェーダのホットリロードと失敗時の挙動 (20 秒)

1. `assets/shaders/common.hlsli` のライティング式に色味を掛ける → 保存 → 1 秒以内に全部変わる
2. **わざと構文エラーを保存** → Console に赤いエラー (ファイル/行付き)。
   **エンジンは旧シェーダのまま動き続ける** → 直すと復帰

## 4:15 決定論とその検証 ★もう 1 つの山場 (45 秒)

1. **タイムトラベル窓**を開き、Play 中に過去 tick へシーク。
   30 tick ごとのスナップショット + 全 tick の入力から再シムし、記録ハッシュと自己照合する
2. ターミナルで `tools\replay_verify.bat` を回す
3. 一言: 「**Debug と Release と CI (WARP) でシミュレーションがビット一致する**、が
   このリポジトリの最大の制約。7 シーンの記録を Debug/Release 両方で再生して
   全 tick のワールドハッシュを突き合わせる。1 tick でも違えば落ちる」
4. 割れたときの道具も見せる: `--hash-diff` でフィールド単位まで落とし、
   `tools\bisect_replay.bat` を `git bisect run` に噛ませる
5. `tools\shot_verify.bat` — 決定的スクショ 22 枚のピクセル回帰

## 5:00 締め (20 秒)

- **Source Control 窓**をさっと見せる (エディタの中で stage → commit → push。
  実体は Rust の cdylib が 6 本の C 関数の裏にいる、ADR-015)
- **Profiler** で CPU スコープと GPU 時間 (RT の 3 レーンを on にして約 2.1 ms / RTX 3060)
- レイヤ構成 (`Editor → GameLogic → Engine → Renderer → Core → Platform`) と
  [`docs/adr/`](adr/) の 17 本の ADR に触れて終了

## 撮り直すときの注意

- `--screenshot` を使う静止画の撮影と違い、この台本は**対話操作**なので
  `--font-embedded` や `--warp` は不要 (むしろ実 GPU の絵を見せたい)
- GPU 時間を画面に出すなら `--frames 20` 以上で回すこと。`GpuTimer` は `kFrames = 6` の
  リングを 7 フレーム目からしか回収しないので、短い run では全部 0.000 ms に見える
- 第 1 部の HAL Collector と第 2 部の三校プロトタイプは**別プロジェクト**。
  切り替えはプロジェクトマネージャから
