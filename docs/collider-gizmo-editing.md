# コライダーのギズモ編集

## 操作

球・箱・カプセルを持つオブジェクトを1つ選び、InspectorのCollider欄で「コライダーを編集」を有効にする。
Scene Viewの既存の移動・回転・拡大ツールとCtrlスナップで編集する。
オブジェクトのTransformは変更せず、Colliderのcenter・rotation・既存の寸法を変更する。
球は半径を一様に変更し、回転操作は無効。箱は軸別の半サイズ、カプセルは横軸で半径、縦軸で全高を変更する。
拡大時は正の寸法を維持し、カプセルの全高を直径以上に制限する。
選択変更で編集モードを解除する。ドラッグ全体はUndo／Redoの1操作になる。
メッシュ・凸包・地形、複数選択、コライダーのワイヤー直接選択は対象外。

## データと互換性

Colliderのcenterはローカル位置、rotationはローカルQuaternion。欠落時はゼロ位置・単位回転となる。
オブジェクトのスケールで寸法と中心を変換し、ローカル回転をオブジェクトの基底へ合成する。
回転によるせん断は導入せず、従来の基本形状とスケールの近似規則を維持する。
ソルバの剛体原点と衝突形状中心を分け、Transformへ中心オフセットを二重に書き戻さない。
新フィールドは保存・Prefab上書き・Undo・状態ハッシュの対象。DLL公開APIスロットは変更しない。
コンポーネントのサイズとハッシュ対象フィールドが増えるため、以前のバイナリスナップショットやReplayのハッシュとの互換性は保証しない。

- 親の回転・非一様スケール・負スケール・ゼロスケール時の操作と表示。
