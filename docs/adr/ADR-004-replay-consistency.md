# ADR-004: 規則 + 自動テストによる Debug/Release 一貫性保証

## 決定
コーディング規則 (spec 11.2) に加えて、リプレイ再生 + フレーム毎ワールド状態ハッシュ比較による自動検証 (spec 11.3) を実装する。規則は tools\check_rules.ps1 の静的検査でも強制する。

## 理由
- 規則だけではヒューマンエラーを防げない。ハッシュ列の機械的比較なら 1 フレームの乖離も検出できる
- 乖離フレームと該当エンティティを特定できるよう、エンティティ毎のサブハッシュを保持する

## トレードオフ
- 決定論を壊す操作 (可変 dt、非管理 RNG、不安定ソート等) が全面禁止になり、実装の自由度が下がる
