# ADR-001: ハイブリッド ECS の採用

## 決定
外部 API は Unity 風 (`GameObject` / `GetComponent<T>`)、内部ストレージはアーキタイプベース ECS (SoA) とする。

## 理由
- Unity 互換ワークフローの開発効率と、ECS のキャッシュ効率・バッチ処理性能を両立する
- 前作 BOMB DRIFT の純 ECS で経験した API の使いにくさを、EntityID を包む軽量ハンドルのファサードで解決する

## トレードオフ
- 二重構造 (API 層 / ストレージ層) の実装コスト
- `GetComponent<T>` が返すポインタはアーキタイプ移動で無効化されるため「当該フレーム内のみ有効」という規約が必要 (フレームを跨ぐ参照は EntityID で保持する)
