# ADR-003: スクリプト状態のエンジン側保持

## 決定
スクリプトのメンバ変数相当 (`moveSpeed` 等) は、リフレクション登録された POD データとしてエンジン側の ECS ストレージに保持する。GameLogic.dll はロジック (関数) のみを持ち、状態を所有しない。

## 理由
- DLL リロード時に状態のバックアップ・復元が原則不要になる (spec 8.4)
- スクリプト状態が通常のコンポーネントと同じ経路 (リフレクション表) で Inspector 表示・シリアライズ・ワールドハッシュの対象になる

## トレードオフ
- フィールドは REGISTER_SCRIPT による登録が必須 (POD 型に限定される)
- 未登録の global / static 変数は永続を保証しない (プロジェクト規約で使用禁止)
